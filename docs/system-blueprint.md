# 恒达电机新品开发系统蓝图

## 1. 建设目标

系统以新品项目为主对象，以订单和客户需求为输入，以受控表单、审批和证据为质量关口，覆盖从商机立项到图纸/BOM/工艺定型，再到后续设计变更和资料归档的完整闭环。

核心控制原则：

1. 每个项目必须有唯一项目编号、负责人、计划周期、当前关口和风险等级。
2. 订单、客户、产品型号、电机代号、技术协议和交付日期均可追溯。
3. 关口完成以“表单 + 审批 + 附件证据”为准，不能只修改百分比。
4. 计划日期、实际日期、延期天数和问题责任人全部留痕。
5. 图纸、BOM、工艺、检验标准和变更记录按版本归档。
6. 写操作由服务端再次校验岗位权限，不能只依赖页面隐藏。

## 2. 端到端流程

| 关口 | 主要责任 | 必要产出 | 放行条件 |
| --- | --- | --- | --- |
| 立项决策 | 销售、技术、管理层 | SJ-01 立项申请 | 市场、技术、成本、风险和交期意见完成 |
| 设计策划 | 技术总监、项目负责人 | SJ-02、SJ-03 | 任务、团队、阶段计划、接口和资源明确 |
| 输入评审 | 设计、销售、质量 | SJ-04 | 合同、标准法规、技术协议和边界完整 |
| 设计输出 | 设计科、工艺科 | SJ-10、图纸、BOM | 输出满足采购、制造、检验和安全要求 |
| 输出评审 | 跨部门评审组 | SJ-05 | 问题、责任人、期限和复核结论明确 |
| 样机验证 | 制造、质量、技术 | SJ-06、试验报告 | 样机、型式试验、计算或仿真结论通过 |
| 设计确认 | 销售、客户、技术 | SJ-07、SJ-08 | 客户试用或鉴定结论通过 |
| 定型下发 | 技术、工艺、质量 | 受控图纸/BOM/工艺/检验文件 | ERP/CAXA/受控文件同步完成 |
| 变更归档 | 变更发起与受影响部门 | SJ-09 | 重审、通知、库存处置和版本同步完成 |

全新产品默认执行全部关口；派生/变型产品至少执行设计任务书，其余关口由技术负责人按风险裁剪并记录原因。总体周期可用“设计 : 工艺 : 制造 = 2 : 1 : 7”作为初始排期基线，再按订单交期倒排。

系统对全新产品禁止流程裁剪；派生/改进产品只能由经营管理层或技术总监裁剪非强制关口，并必须填写等同性、风险和替代验证依据。立项、设计任务和定型下发不可裁剪。项目暂停、恢复和终止均形成审计事件；终止时关闭待审批和未实施变更，但保留订单关系、既有文件和问题记录供追溯。

## 3. 角色与权限

| 角色 | 主要职责 |
| --- | --- |
| 系统管理员 | 用户、岗位、权限、基础数据和审计管理 |
| 经营管理层 | 立项/定型决策、重大风险与资源协调 |
| 技术总监 | 全流程策划、技术关口批准、变更批准 |
| 项目负责人 | 项目、计划、跨部门协同和交付闭环 |
| 设计工程师 | 输入、计算、图纸、BOM、技术文件 |
| 工艺工程师 | 工艺性评审、工艺文件、工装与过程验证 |
| 质量工程师 | 检验、试验、验证和质量问题闭环 |
| 制造/装配 | 样机计划、制造、装配与现场问题反馈 |
| 采购 | 样件/材料、供应商、规格和交期保障 |
| 销售 | 客户需求、订单、技术协议和试用确认 |
| 财务 | 目标成本、实际费用和成本评审 |
| 只读访客 | 经授权范围内查看项目和报表 |

系统权限拆分为项目、订单、表单、审批、变更、问题、文件、报表、用户和审计十个域。每个域分别控制查看、创建、编辑、提交、批准或管理动作。

## 4. 数据对象

- 项目：编号、类型、来源、客户、订单、产品型号、负责人、阶段、风险、预算和成本。
- 里程碑：关口、责任部门/人员、计划/实际日期、状态、完成度、证据数量。
- 订单：订单号、客户、型号、数量、金额、交期、状态和关联项目。
- 表单记录：表单编号、项目、版本、字段载荷、草稿/提交状态、更新人和时间。
- 审批：表单、提交人、审批角色、期限、结论、意见和决策时间。
- 问题：类别、严重度、责任人、期限、状态和解决说明。
- 变更：变更号、原因、对象、影响、通知要求、库存处置、状态和期限。
- 文件：项目、表单、文件名、对象键、类型、大小、版本、上传人和时间。
- 活动：操作者、动作、对象、详情和时间，用于审计和项目时间线。

## 5. 进度与预警规则

- 项目进度由关口完成度聚合，不允许手工虚报总体百分比。
- 到期未完成里程碑进入延期清单；高/严重风险和受阻里程碑置顶。
- 订单交期早于项目计划结束时显示交付冲突。
- 待审批超过期限、问题超过责任期限、变更超过执行期限分别预警。
- 关口放行前检查必填表单、审批状态和证据附件数量。
- 全新产品的设计策划关口同时校验 SJ-02 设计任务书和 SJ-03 开发计划书。
- 订单型号必须与项目型号一致，项目计划完成日不得晚于订单交期。
- 仪表盘同时显示在研数量、准时率、延期节点、待审批、未关闭问题和预算执行。

## 6. 上线治理建议

首轮上线应先确认组织用户、现有在研项目、客户与订单主数据，再导入历史表单和图纸。权限以最小授权为原则；技术总监和管理层审批角色不得由项目执行人自行替代。正式运行前需完成数据备份策略、附件保留周期、编号规则、电子审批效力和 ERP/CAXA 接口字段映射评审。
