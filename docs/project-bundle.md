# 项目完整离线归档

项目页“离线归档 ZIP”直接触发浏览器下载，不通过前端一次性缓存所有附件。发生前置错误时在新页显示原因，原项目页保持打开。

## 包内内容

- `00_归档说明.txt`：项目、生成时间、导出人、数量、使用说明及限制。
- `01_开发程序.docx`：当前十阶段程序与变更摘要，沿用已验证的原生Word导出。
- `02_完整项目数据.xlsx`：当前记录、全部项目操作日志及已保存的阶段历史快照，沿用现有原生Excel导出。
- `03_附件原件/阶段/序号_文件名`：当前项目所有附件记录对应的原件，包括仍保留的旧版报告，不修改内容。附件数为0时无此目录。
- `04_附件清单.json`：原文件名、包内路径、附件ID、阶段、版次、规格/记录关联、上传人/时间、长度与ETag，便于查证；不暴露存储对象路径。阶段版本在清单中列出。

## 保护与限制

下载首先沿用项目可见性校验。附件必须属于该项目和有效阶段，存储路径也须匹配项目；记录重复或异常拒绝继续。逐项读取元数据，校验存在、长度及ETag后才开始生成数据文件和返回ZIP。

读取原件使用ETag条件，失败时不返回文件体；每个输入文件按流式长度核对，完成后才写ZIP尾目录。序号避免同名、大小写或名称规范化后冲突；路径分隔符、控制/双向字符、前后点和超长名称被处理，原名仍在清单保留。ZIP无需生成空目录条目。

附件逐个读取，输出按下游读取速度推进；取消下载关闭当前输入，不继续读取后续原件。Word和Excel仍在内存生成，因此大型结构化数据与极多附件索引的性能尚需进一步验收，不能把附件流式化推广为所有数据均恒定内存。ZIP使用项目已安装的fflate 0.7.5（本次显式列为直接依赖），STORE格式不再压缩原件，保留CRC校验；没有解压不受信任数据的服务端入口。Web运行时通过FixedLengthStream传送精确长度，长度不符将使下载失败。

标准ZIP不支持本实现中的ZIP64：总大小必须小于4GB，文件数至多65535（4项为说明、Word、Excel、清单）。预先检查并明确报错，不静默丢附件或截断。若存储对象在预检查后被改动或删除，下载会中止；不得把部分下载文件作为有效档案。

文件未加密，包含图纸和报告等敏感资料，仅供有权限的人放到受控目录保存。CRC/ETag不等同数字签名、防篡改签章或病毒扫描。原附件可能包含宏等可执行内容，打开时仍需遵守企业安全要求。

项目归档的13组查询使用同一次数据库只读事务：项目、客户、订单、成员、规格、阶段、表单、零部件、试验、检验、附件索引、操作日志和版本历史不会因查询之间发生修改而混用新旧数据。各查询在数据库中限制项目范围，并按事务内的当前账户启用状态、角色和成员关系校验权限，不使用请求开始时缓存的管理员权限。说明和清单区分数据读取时间（`capturedAt`）与文件生成时间（`generatedAt`）；读取后发生的更改不进入本包。

附件字节位于另一存储，不属于D1读取事务。归档以该事务的附件索引为准，再预检查对象并条件读取；正常上传使用独立对象键，不覆盖旧原件。不能据此保证管理员绕过系统直接替换对象后的历史字节可还原。读取时获准的下载，不因之后撤销权限而自动追回或中断。仍需企业正式审批和受控留存；不是整库备份，不能直接导入恢复。历史缺失的快照和已丢失的附件不能由导出工具补回。

## 验证与依据

- `tests/project-bundle.test.mjs`：独立JSZip解析及CRC核对、文件原字节/重名Unicode映射、无附件、缺失/错归属/长度异常、ETag变化、截断包不可完成、取消/背压及160MiB累计合成附件流式消费。大容量测试在Node上进行，未把它当作正式Worker极限压测。
- `tests/local-production-runtime.mjs`：正式本地Worker中的受权ZIP下载、三份真实隔离R2原件逐字节核对、同名中文报告保留、包内DOCX/XLSX结构、长度和CRC、未登录/非成员拒绝。
- `tests/archive-snapshot.mjs` / `tests/archive-snapshot-runtime.mjs`：同一次只读事务、读取前/后修改边界、并发更新与13组结果对应、成员移除/账户停用/旧管理员角色拒绝，以及工作区同次读取；第二个入口需要真实隔离本地D1运行环境，具体执行结果以完成度审计为准。
- 数据库事务语义参照[Cloudflare D1 batch说明](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)。工作区与项目概览Excel的数据读取也使用单次batch，但概览仍导出权限范围内全量项目，不按页面筛选裁剪。
- 实现参照[Cloudflare R2条件读取文档](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)和[FixedLengthStream说明](https://developers.cloudflare.com/workers/runtime-apis/streams/transformstream/)，流式ZIP接口参照[fflate维护者说明](https://github.com/101arrowz/fflate/blob/master/README.md)。具体调用同时对照本项目已安装版本源码，不据此宣称上游依赖没有安全告警。
