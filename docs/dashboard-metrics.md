# 项目看板口径与复验

## 目的与数据来源

用途是领导查看新品全流程的当前状态与需要跟进的项目，不是还原历史月末状态。交付面为现有本地应用的项目驾驶舱，不另建静态报告或对外发布。

主数据由 `db/store-v2.ts:getNpdWorkspaceSnapshot` 从本地 `npd_projects` 读取；负责人从 `npd_users` 关联，规格数取 `npd_project_motors`，当前节点责任人取 `npd_project_members` 与 `npd_project_sheets`。API先校验登录，工作区先按管理员/发起人/负责人/成员过滤。`projects` 等首版表不是当前页面数据源，不能与V2表合并统计。

2026-09-07只读核查：V2项目4条，3条进行中、1条已完成；负责人关联缺失0，计划起止反向/进度越界0。当前数据中4条建档时间均为2026-08-29，而已完成项目实际完成于6月，因此系统建档时间不能命名为真实“立项日期”。这不证明全部项目内容都是真实生产记录；现存数据可能包含早期演示记录，不能据此给出公司经营结论。

## 统一项目范围

负责人筛选作用于全看板。先筛权限内项目，再满足以下任一条件：

1. 有效计划周期与所选区间相交（含边界）。
2. 草稿/进行中/暂停，计划开始不晚于今日及区间结束，且区间开始不晚于今日。这样历史逾期未结项目不会在进入新月后消失。

无效计划日期不猜测、不纳入范围，页面显示待核对数量。自定义起止必须完整有效且不反向；年份支持1000～9999。所有业务日期/逾期判断采用北京时间；SQLite UTC建档时间先转换为北京时间再归桶。

## 指标

| 指标 | 分子/范围 | 特别处理 |
|---|---|---|
| 项目总数 | 上述项目范围内记录数 | 含终止项目，便于状态构成加总 |
| 进行中 | 当前状态active | 不含暂停/草稿 |
| 已完成 | 当前状态completed | 不是所选期内完成事件数 |
| 按期完成 | completed且有效实际完成日期≤计划完成日期 | 缺失/未来日期不算按期，另有提示 |
| 未结逾期 | draft/active/paused且计划完成日期<今日 | 暂停不自动顺延，完成和终止不累计当前逾期 |
| 电机规格 | 各项目规格数之和 | 不是台数 |
| 平均进度 | 未终止且进度0～100的项目等权平均 | 分母为有效项目数，无项目显示— |
| 未结高风险 | draft/active/paused且high/critical | 完成和终止不算当前风险 |

图表事件日期仍必须落入选定区间。因此“当前已完成项目数”可以大于“区间内完成数”；口径差异在页面说明。重开项目即使遗留旧实际日期，也不会继续计完成流量。本图不是多次重开/完成事件的次数统计。

## 图表约定

- 状态分布：保留现有五状态环图，粒度为项目，所有状态数量相加等于项目总数；沿用项目品牌状态色并提供文字/数字图例，空集无实心扇区。
- 项目流量：保留现有分组柱图，登记与完成两个同单位的计数。单月1组、半年6组、全年12组；跨长区间按连续月份合并至不超过24组，明示每组起止范围，不静默截断。稀疏数据仍用离散计数柱，不构造趋势线或补造事件。
- 沿用蓝色登记/绿色完成（完成语义）的品牌配色；固定左右顺序、柱顶数字及精确表格提供非颜色辨识。零值柱高为0，不以最小高度暗示有项目。标准柱从零基线起，按相同最大值缩放。
- 现有仪表板容器内允许横向滚动，长区间不通过缩小文字硬挤；查看明细可核对日期和每组两项数量。没有引入新的图表运行库。
