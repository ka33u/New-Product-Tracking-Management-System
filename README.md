# 亨达新品开发

依据《产品开发控制程序》及 HD/JL-SJ-01A1～10A1 表单重构的电机新品开发系统。系统以“项目 → 同系列多个电机规格 → 10 个阶段 Sheet”为主线，贯通销售订单、设计输出、零部件节点、试验报告、质量检验、客户试用、鉴定、变更和完整归档。

## 核心能力

- 项目打开后展示“项目概览 + 10 个阶段 Sheet”，每个 Sheet 有责任角色、计划节点、状态、进度、版本、附件和操作时间戳。
- 一个项目可包含多个同系列具体电机规格，每个规格分别维护检验要求、试验要求、计划节点、试验报告和整机检验记录。
- 六类登录角色：管理员、销售、设计、生产、试验员、质量。仅销售、设计、管理员可建项；管理员查看全部，其他人员查看自己发起、负责或被分配参与的项目。
- 发起人自动取创建人，建项时必须指定项目负责人、生产、试验和质量责任人。
- 销售订单台账支持录入、客户一致性校验、一个项目关联多个订单、解除/重关联及交付日期跟踪。
- 生产确认整机和零部件节点；试验员按规格提交型式/验证报告；质量人员提交整机和零部件检验记录。
- 质量检验要求由设计输出自动引用，后续检验记录不能脱离或自行篡改要求来源。
- 项目总看板支持年度、半年度、月度、自定义区间和个人指标配置，展示状态分布、近 6 月趋势、风险、逾期和重点项目。
- 阶段门校验前置 Sheet、受控表单、零部件完工、规格级试验和质量记录齐套性。
- 支持项目概览 Excel、单项目多工作表 Excel、单 Sheet Word 归档和完整开发程序 Word 归档。
- D1 保存业务数据，R2 保存附件；所有写操作由服务端再次校验权限并写入审计时间戳。

详细架构见 [系统蓝图](docs/system-blueprint.md)，验收证据见 [完成度审计](docs/completion-audit.md)。

## 本地运行

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

系统启动后访问终端显示的本地地址。默认本地演示账号为管理员，首次访问自动初始化六类人员、客户、订单和四个示例项目。

## 验证与迁移

```bash
npx tsc --noEmit
npm run lint
npm run build
npm test
npm run db:generate
```

`npm run test:store` 会在内存 D1 适配器上验证：六角色权限、多规格建项、订单关联、项目可见范围、必填表单、阶段门、生产确认、试验提交、质量要求引用和操作时间戳。

## 关键目录

- `app/components/NpdWorkspace.tsx`：主导航、项目组合、订单、任务和人员权限
- `app/components/npd/ProjectWorkspace.tsx`：项目概览与 10 Sheet 工作台
- `app/components/npd/Dialogs.tsx`：建项、表单、节点、试验、检验、订单与权限操作
- `app/components/npd/Dashboard.tsx`：多周期图形化项目看板
- `db/store-v2.ts`：D1 初始化、访问控制、阶段门和业务写操作
- `db/schema.ts`：Drizzle V1/V2 兼容数据模型
- `lib/sheets-v2.ts`：10 个 Sheet 与原表单映射
- `lib/forms.ts`：HD/JL-SJ-01A1～10A1 受控字段定义
- `lib/export-v2.ts`：Excel 与 Word 归档生成
- `app/api/files/`：R2 附件上传和鉴权下载
